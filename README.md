# 🤖 CodeWhisperer AI

### Generative AI Programming Tutor

[🚀 **Live Demo**] https://code-whisperer-ai.vercel.app

CodeWhisperer AI is a Generative AI-powered programming tutor designed to help students understand programming concepts, debug code, and improve problem-solving skills.

## ✨ Features

- 💬 AI-powered programming assistance
- 🧠 Beginner-friendly explanations
- 🐛 Code debugging and analysis
- 📊 Time and space complexity analysis
- 📁 Upload and analyze source-code files
- 🎯 Multiple learning modes
- 💡 Hints and guided problem solving
- 📱 Interactive web interface

## 🎯 Learning Modes

- **Friendly** – Simple and encouraging explanations
- **Beginner** – Easy-to-understand explanations
- **Interview** – Interview-style programming practice
- **Debug** – Focused code debugging
- **Hint** – Gives hints instead of directly revealing the solution
- **Quiz** – Programming quiz practice
